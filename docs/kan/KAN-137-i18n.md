# KAN-137 · SOS global ES/EN

El SOS es un acceso rápido global: botón fijo en la barra inferior (o flotante cuando la barra no se ve), cuenta regresiva de 5 s y auditoría local (`wellness.sos.audit.v1`). Todo el texto visible usa `t()`; las claves nuevas están al final de `src/i18n/es.json` y `src/i18n/en.json`.

Claves retiradas (promesa de atención profesional o sin uso): `Ayuda en camino`, `Tu equipo médico y contactos`.

| SOS EN MARCHA | SOS STARTED |
| Llamada automática al terminar | Automatic call when it ends |
| segundos | seconds |
